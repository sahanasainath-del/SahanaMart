# SahanaMart – Multi-Seller E-Commerce Marketplace

An end-to-end multi-role storefront project built completely in Python using Streamlit.

## ⚡ Setup and Execution
1. Install Streamlit framework: `pip install streamlit`
2. Launch code locally: `streamlit run app.py`
